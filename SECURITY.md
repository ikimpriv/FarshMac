# Security reports

Please do not post credentials, private keys, host inventories, or exploit details in a public issue.

Use GitHub's **Security → Report a vulnerability** feature when private vulnerability reporting is enabled for this repository. If it is not available, open an issue asking the maintainer to establish a private reporting channel, without including vulnerability details.

Include the affected version, macOS version, reproduction steps using synthetic data, and the likely impact. The project is an early release; there is no promised response-time SLA. Fixes target the current version.

Ordinary defects can be reported through the bug-report template. For filesystem, archive, terminal escape, SSH host verification, and credential handling issues, prefer private reporting when a security boundary may be affected.
