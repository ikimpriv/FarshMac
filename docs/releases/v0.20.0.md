# FarshMac 0.20.0 — File-operation dialogs and recovery

FarshMac is an open-source macOS file manager written in Go, **inspired by Far Manager**. This preview brings more of its file-operation workflow to macOS. It is an independent project, not an official Far Group release.

## Changes since 0.19.1

- Existing-file dialogs now show both sizes and modification times, with **Overwrite, Skip, Rename, Append**, and **Remember choice**.
- Failed transfers and deletions offer **Retry, Skip, Skip all, Cancel**, including failures inside folders. Read-only files and metadata-preservation failures have separate confirmations.
- Existing destination folders merge correctly instead of accidentally creating an extra nested folder.
- Same-server FTP/SFTP moves support folder merging and conflict decisions.
- Append stages the result before replacing the destination. If deleting a moved source fails, Retry repeats only deletion, preventing duplicate appends.
- Errors remain visible, show full paths and system messages, and support PageUp/PageDown for long text. Completed batches report skipped items.
- Added regression tests for local and remote conflicts, access failures, cancellation, metadata recovery, and parallel operations.

Already completed items are not rolled back when a batch is cancelled. Remote metadata and replacement guarantees depend on the server. Trash errors never silently become permanent deletion. See [file-operation behavior](https://github.com/ikimpriv/FarshMac/blob/v0.20.0/docs/FILE_OPERATIONS.md) for details.

## Download and install

Download **FarshMac-0.20.0-macOS-universal.zip**, unzip it, and move **FarshMac.app** to Applications. The universal executable contains Apple Silicon and Intel builds and targets macOS 12 or later.

The `.sha256` file verifies the ZIP:

```sh
shasum -a 256 -c FarshMac-0.20.0-macOS-universal.zip.sha256
```

This preview is signed with the project's **persistent self-signed development certificate**. It is **not Developer ID signed or notarized**, and macOS may block normal opening of a downloaded copy. If you choose to run it, use the per-application approval in System Settings → Privacy & Security; do not disable Gatekeeper globally. Signing is separate from Full Disk Access: grant that access explicitly if you want to browse protected folders. After changing from older ad-hoc builds, add the new copy once and restart the app.

## First steps

- **Tab** switches panels; **Cmd+O** switches panels/terminal.
- **F3/F4** views/edits; **F5/F6/F7** copies/moves/creates a folder.
- **F8** moves to Trash; **Shift+F8** deletes permanently.
- **F9** opens menus; **F1** opens the keyboard reference; **Cmd+Q** quits.

## Preview limitations

This is an early release. Archive panels are read-only; Windows Far plugins and Lua macros are not supported. Remote metadata support depends on the server. Text editing is limited to 64 MiB and syntax highlighting to 1 MiB. Cached folder sizes are snapshots, not a live filesystem index. Native UI behavior and Intel/older-macOS runtime coverage remain less complete than model and integration tests.

Please report reproducible issues with the version, macOS version, and non-sensitive sample data. The source is MIT licensed; bundled components and the original Far Manager icon retain their own licenses and attribution.
