FarshMac 0.23.0 brings Docker workspaces and live container diagnostics into the two-panel workflow. Browse files, keep a shell open for each context, inspect resource usage, and investigate traffic without losing your place.

FarshMac is an independent macOS project inspired by **Far Manager**. This remains an early preview.

## Docker workspaces

Connect to Docker from the Left/Right menus or Alt+F1/F2. Browse Compose projects, standalone containers, images, networks and volumes. F3 and Quick view present structured object information; context actions adapt to object type and state instead of duplicating file shortcuts. Container and volume files support normal file operations and editing where permissions allow.

## PodToast: work inside minimal containers

Explicitly attach [PodToast](https://github.com/ikimpriv/PodToast), including to distroless targets, for filesystem access and diagnostics. Toolbox commands run in the ephemeral container while using the target filesystem location; shell labels make that distinction visible. Shared PID namespaces can reuse an eligible agent across targets.

The default image is **ghcr.io/ikimpriv/podtoast:0.8.2**, published for Linux amd64 and arm64. Existing agents are reused. The version/update action can attach a newer agent and switch to it after connection succeeds. Superseded agents stop only when replacements cover their targets and active operations have drained; terminated ephemeral-container records remain in the pod.

Mount points are highlighted with container filesystem, ConfigMap, Secret, ephemeral-volume or PVC information. PodToast computes directory summaries inside the container, with intermediate results and cancellation, for Quick view and folder-size calculation.

## Metrics that fit the workflow

- **Ctrl+Shift+Q** toggles Quick Live Metrics in the opposite panel for selected Kubernetes pods/containers or Docker containers. Charts use the current theme, readable time/value axes and subtle grids. Request/limit lines appear for a single-container selection when known.
- **Working set** is the default memory view. Press **M** in the metrics panel, or click its selector, to choose **Applications (anonymous)**, **File cache**, or **Total**. Working set excludes inactive file cache; it still includes active cache and kernel memory. Missing breakdown data is shown as unavailable, not replaced with Total.
- PodToast keeps up to ten minutes of bounded metric history before a dashboard is opened. New sessions replay that history before live updates.
- Detached dashboards discover metrics through annotations, PodMonitor resources and candidate ports. Search series, choose their destination chart, select raw/delta/rate display, and normalize mixed scales. Multiple windows remain independent.
- Dialogs and menus obscure only their own area and shadow; charts remain visible and continue updating behind them.

## Network diagnostics

A separate traffic window shows observed TCP/UDP connections, incoming/outgoing port aggregates and charts for selected flows or groups. Fault injection is a separate explicit action, with conditions, blocking and reset controls for supported TCP proxy traffic. Capture and intervention require the relevant permissions; TLS payload decryption is not included.

## Shells, files and navigation

Shell sessions retain their state and output when switching between local, SSH, Kubernetes and Docker contexts. Commands entered in panels run in their context and return to the panels on completion; Cmd+O reveals the retained terminal.

Recent connections restore panel locations directly. Additional improvements include Finder-style email attachments and Open In actions, ZIP/tar.gz/tar.bz2 creation, selection cleanup after successful operations, iCloud/File Provider materialization before viewing/editing, and generated proc-file viewing. Docker catalog sorting and renewed Kubernetes OIDC credentials are handled more reliably.

## Install and upgrade

Download **FarshMac-0.23.0-macOS-universal.zip**, quit the running application, unzip, and replace FarshMac.app. The bundle includes Apple Silicon and Intel executables and targets macOS 12+.

Verify the download with:

```sh
shasum -a 256 -c FarshMac-0.23.0-macOS-universal.zip.sha256
```

This preview uses the project's persistent **self-signed development certificate**; it is not Developer ID signed or notarized. macOS approval and Full Disk Access are separate from signing continuity. See [publishing documentation](https://github.com/ikimpriv/FarshMac/blob/main/docs/PUBLISHING.md).

For the new memory breakdown, update existing PodToast agents through the version/update action. Older agents remain usable, but cannot supply metrics they do not implement. Metrics, storage statistics and diagnostics depend on cluster permissions and runtime visibility. Anonymous memory, file cache, working set and Total are overlapping views, not additive components.

Archive panels remain read-only. Kubernetes move/rename uses create-then-delete rather than an atomic rename. Universal compilation does not imply runtime validation of every feature on both architectures or every supported macOS version.
