FarshMac 0.24.0 improves document viewing: read Markdown with pictures in the current theme, browse every page of a PDF without leaving F3, and move through folders without waiting for obsolete Quick Look calculations.

FarshMac is an independent macOS project inspired by **Far Manager**. This release remains an early preview.

## Markdown with pictures

F3 and supported Quick Look panels now render Markdown with system fonts, headings, tables, task lists, code blocks, quotes and footnotes. The background and colors follow the FarshMac theme.

Local and relative raster images are resolved from the document's source filesystem, including supported remote and container sources. Loading runs in the background with limits on document size, image count and decoded image size. HTTP images are not fetched automatically; embedded HTML and scripts are not executed.

**Cmd+Shift+M** switches between formatted Markdown and source. Source search and editing retain the existing viewer/editor controls. Large Markdown documents display a bounded preview with a truncation notice.

## Browse the whole PDF in F3

The PDF viewer can now display **every page**, with a page counter and navigation controls:

- **Page Up / Page Down** or **[ / ]**: previous / next page.
- **Home / End**: first / last page.
- **0**: fit the whole page; **W**: fit its width.
- **+ / −**: zoom; arrow keys, Space / Shift+Space and the mouse wheel scroll within the page.
- **Esc**: return to the panels.

Zoom is retained between pages. The current page stays visible at full brightness until the next image is decoded, eliminating the dimming flash during page changes. Page dimensions and rotation are respected; the rendering bug that shrank PDF content inside a large white page is fixed.

Pages are decoded on demand in a separate helper process. Switching pages or closing the viewer cancels superseded work, and memory use does not grow with the number of pages. This is a graphical, page-by-page viewer; PDF text search, selection, annotations and continuous multi-page scrolling are not included.

## Quick Look cancellation

Leaving a file or folder, changing the panel context, hiding Quick Look or switching to the terminal immediately cancels the previous preview work. This covers recursive directory summaries, remote requests, image previews and Markdown image loading.

A new selection no longer waits for an obsolete request to finish. Late results cannot overwrite the new preview or clear its loading state. Focusing the Quick Look panel itself keeps its current preview running.

## Validation

Regression tests cover PDF content scaling and rotation, page selection, zoom and navigation, asynchronous image replacement, Markdown rendering and image loading, and Quick Look cancellation and stale-result handling. The release pipeline runs Go tests with the race detector and renderer tests before packaging.

## Install and upgrade

Download **FarshMac-0.24.0-macOS-universal.zip**, quit FarshMac, unzip it and replace the application. The bundle contains Apple Silicon and Intel executables and targets macOS 12+.

Verify the download with:

```sh
shasum -a 256 -c FarshMac-0.24.0-macOS-universal.zip.sha256
```

The application uses the project's persistent **self-signed development certificate**, not Developer ID signing or notarization. macOS approval and Full Disk Access remain separate from signing continuity. Universal compilation does not establish runtime validation of every feature on both architectures or every supported macOS version.
