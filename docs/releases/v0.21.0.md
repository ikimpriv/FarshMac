# FarshMac 0.21.0 — File safety, links, and window bookmarks

FarshMac is an open-source macOS file manager written in Go, **inspired by Far Manager**. It is an independent project, not an official Far Group release.

## Changes since 0.20.0

- Editor access checks now consider both the file and its parent folder. Files that may not be writable offer View / Edit anyway / Cancel. Open and save failures retain useful error details and unsaved edits.
- Saving detects external changes and supports an explicit Save in place option when atomic replacement is unavailable. Save in place is non-atomic; choose it deliberately.
- Local copy/move offers Smart, As is, and Copy contents modes for symbolic links. Smart mode preserves the referenced object when relative links move; hard-linked files copied together retain their relationship.
- Improve local and remote conflict recovery, cancellation, progress reporting, and connection trust handling, with expanded regression tests.
- Folder and document bookmarks now share window-local slots: **Cmd+Option+0…9** stores a bookmark and **Cmd+0…9** recalls it. These shortcuts replace the earlier folder-bookmark combinations; bookmarks are not persisted after the window closes.
- **Enter** opens `.app` bundles as folders. Use **Shift+Enter** to open them with macOS.
- **F3** opens supported images in the graphical viewer.

This release includes the implementation-backlog fixes merged in PR #6. It does not introduce system Quick Look integration, far2l plugin compatibility, or Kubernetes panels; specifications and discussions do not imply those features are available.

## Download and install

Download **FarshMac-0.21.0-macOS-universal.zip**, unzip it, and move **FarshMac.app** to Applications. The universal executable contains Apple Silicon and Intel builds and targets macOS 12 or later.

The `.sha256` file verifies the ZIP:

```sh
shasum -a 256 -c FarshMac-0.21.0-macOS-universal.zip.sha256
```

This preview is signed with the project's **persistent self-signed development certificate**. It is **not Developer ID signed or notarized**, and macOS may block normal opening of a downloaded copy. If you choose to run it, use the per-application approval in System Settings → Privacy & Security; do not disable Gatekeeper globally. Signing is separate from Full Disk Access: grant that access explicitly if you want to browse protected folders. After changing from older ad-hoc builds, add the new copy once and restart the app.

## First steps

- **Tab** switches panels; **Cmd+O** switches panels/terminal.
- **F3/F4** views/edits; **F5/F6/F7** copies/moves/creates a folder.
- **F8** moves to Trash; **Shift+F8** deletes permanently.
- **F9** opens menus; **F1** opens the keyboard reference; **Cmd+Q** quits.

## Preview limitations

This is an early release. Archive panels are read-only; Windows Far plugins and Lua macros are not supported. Remote metadata support depends on the server. Text editing is limited to 64 MiB and syntax highlighting to 1 MiB. Cached folder sizes are snapshots, not a live filesystem index. Native UI behavior and Intel/older-macOS runtime coverage remain less complete than model and integration tests.

Please report reproducible issues with the version, macOS version, and non-sensitive sample data. The source is MIT licensed; bundled components and the original Far Manager icon retain their own licenses and attribution.
