FarshMac 0.27.0 adds Kubernetes workload restarts and makes batch operations easier to control, with progress, retry/skip decisions and predictable selection handling.

FarshMac is an independent macOS project inspired by **Far Manager**. This release remains an early preview.

## Restart Kubernetes workloads

Use **F11 / Alt+Enter → Restart rollout…** on Deployments, StatefulSets or DaemonSets. It works with a single object or a selection; mixed selections show the eligible count before confirmation.

Restart updates the pod-template annotation while preserving replicas and the configured update strategy, including Recreate and StatefulSet partitions. UID and resourceVersion checks protect against replaced or concurrently changed objects. The API response is checked for an unexpected replica-count change. Paused Deployments and OnDelete strategies produce an explanatory error instead of deleting pods. Jobs, CronJobs and ReplicaSets do not offer rollout restart.

A successful request starts the controller's rollout; it does not mean every pod has already restarted.

## Progress instead of completion reports

Batch mutations, including Docker actions and ephemeral-container/PodToast attachment and updates, show progress and close it when finished. They no longer open a completion report.

When an object fails, choose:

- **Retry** — repeat the current operation.
- **Skip** — leave this object selected and continue.
- **Skip all** — continue processing, automatically skipping only objects that fail.
- **Cancel / Esc** — stop further work; completed changes remain in place.

Successful objects are unmarked. Skipped, failed and unprocessed objects stay selected. A pod is unmarked only when all its selected container targets succeed. Requested diagnostic content, such as logs, still opens in the viewer.

## Most recent connections first

The **15 recent connections** are now ordered strictly by last use, newest first, regardless of whether they are Docker, Kubernetes, FTP or SFTP connections.

## Installation

Download **FarshMac-0.27.0-macOS-universal.zip**, quit FarshMac, unzip, and replace the application. The bundle includes Apple Silicon and Intel executables and targets macOS 12+.

```sh
shasum -a 256 -c FarshMac-0.27.0-macOS-universal.zip.sha256
```

Regression checks cover workload restart patches, replica preservation, unsupported states, batch Retry/Skip/Skip all/Cancel decisions, selection retention, and mixed-type recent ordering. The release pipeline runs checks and race tests before signing and packaging.

The release uses the existing persistent self-signed identity. It is **not Developer ID signed or notarized**. macOS may require approval under System Settings → Privacy & Security. Full Disk Access remains a separate permission.
