FarshMac 0.26.0 simplifies Kubernetes connections, adds SSH access to remote clusters, and makes context menus work with multiple selected objects.

FarshMac is an independent macOS project inspired by **Far Manager**. This release remains an early preview.

## Kubernetes connections with less setup

For an SSH connection, enter the server address and an optional username. FarshMac tries automatic authentication first and asks for a private key, password, or SSH settings file only when needed. Successful authentication methods are remembered; passwords and key passphrases remain in memory for the application session.

Configuration files are discovered on the server or in local kubeconfig locations. A two-column browser shows files on the left and their contexts on the right, with keyboard and mouse navigation. **Custom kubeconfig files** lets you paste and name configurations, reuse different contexts, and connect directly or through SSH.

SSH forwarding supports remote loopback APIs such as kind and k3s, including shell/exec streams. TLS verification and SSH host-key checks remain enabled. Unknown host keys require confirmation; changed or revoked keys are rejected. Pasted credential files are stored privately, and passwords are excluded from saved connection profiles.

## Faster navigation and selection-aware actions

- The recent connections list now shows **15** entries, grouped Docker, Kubernetes, then other remote connections. Previous panel locations are retained.
- Kubernetes bookmarks preserve the connection profile, path, and cursor when restored.
- Context menus account for multiple selected files, Kubernetes resources, and Docker objects. Batch actions include ephemeral-container attachment, PodToast updates, Docker lifecycle operations, diagnostics, image exports, volume backups, network membership changes, and Compose recreation.
- Single-context interactive actions are hidden for multiple selections. Batch operations retain per-object results and cancellation.
- Viewer/editor handling of **Ctrl+Q** and **Ctrl+Shift+Q** no longer quits the application. **Cmd+Q** remains the quit shortcut.

## Docker connections and container visibility

Create Docker SSH contexts using host details, an existing SSH alias, or a private key, without changing the default Docker CLI context. Container panels show Status and Age, health and exit information, dim inactive containers, and highlight failures.

PodToast coverage is visible for containers, volumes, and Compose projects. Remote Docker toolbox setup matches the target AppArmor profile, verifies agent access before reporting success, and offers repair or replacement of existing helpers.

## Installation

Download **FarshMac-0.26.0-macOS-universal.zip**, quit FarshMac, unzip, and replace the application. The bundle includes Apple Silicon and Intel executables and targets macOS 12+.

```sh
shasum -a 256 -c FarshMac-0.26.0-macOS-universal.zip.sha256
```

The release pipeline runs checks and race tests before signing and packaging. The bundle uses the existing persistent self-signed identity; it is **not Developer ID signed or notarized**. macOS may require approval under System Settings → Privacy & Security. Full Disk Access remains a separate permission.
